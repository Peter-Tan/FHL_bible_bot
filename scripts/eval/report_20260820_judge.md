## v8 的典型失敗模式（judge 逐題 rationale 歸納）

不只是「引用變少」，而是**實質錯誤**：

| 題 | 失敗 |
|---|---|
| `figu04` | 問「推基古」卻整篇答「提多」——人物張冠李戴，且未誠實說明查無資料 |
| `figu03` | 問以斯拉記的 650 他連得，整篇談創世記約瑟屯糧——主題完全錯置 |
| `synt03` | 把「得4:1」誤判為加拉太書，並**捏造**該處經文 |
| `word02` | **捏造 Strong's 編號** `SNHH2632`（正確為 H4960） |
| `word06` | 誤稱 `SNH03374` 不符 5 位數格式（03374 本就是 5 位數），說明錯誤且誤導 |

共同型態：**查不到資料時不說「查不到」，而是拿相鄰的東西頂替**。
這正是 coverage 掉到 3.50 的主因，也是 prompt 調校要對付的核心行為。
